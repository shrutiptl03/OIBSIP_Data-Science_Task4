# Task 4: Email Spam Detection


## Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning to classify SMS or email messages as Spam or Ham (Not Spam).

## Objective
Detect unwanted spam messages.
Learn text preprocessing and NLP techniques.
Build a text classification model.
Steps Performed
Loaded the SMS Spam dataset.
Cleaned and preprocessed text data.
Converted text into numerical features using TF-IDF.
Encoded labels (Spam/Ham).
Split dataset into training and testing sets.
Trained a Naive Bayes classifier.
Evaluated model using accuracy, precision, recall, and confusion matrix.

## Tools Used
Python
Pandas
NumPy
Scikit-learn
NLTK
TF-IDF Vectorizer

## Outcome
The model achieved high accuracy (around 98–99%) and successfully classified messages as spam or legitimate, demonstrating the effectiveness of NLP in text classification.
